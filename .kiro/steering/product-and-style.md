# Product and Style

## Name
The product is called "Grimoire". Always pair it with the tagline
"build small apps from cards, in plain English" in user-facing copy.
Stacks are "spellbooks" in the UI; scripts are "spells".

## Vision
A browser-based tool where non-programmers build small interactive apps
from stacks of cards. Users describe behavior in plain English, get a
readable spell, and can edit it.

## Non-goals
Accounts, real-time collaboration, native mobile apps, heavy media.

## Rules
- Never use Apple names, logos, assets, sample stacks or code.
- Visual style: spooky-retro, candlelit, high contrast.
- Accessibility is required: keyboard navigation, reduced-motion
  option, readable contrast. Spooky effects must never hide content.
- Error messages are plain language and point to the exact line.
